## Executive Summary

Arcane Typer is an arcade typing defense game set in an enchanted library. Words descend toward an arcane protective barrier, and the player must destroy them via precise typing before the barrier collapses. Successful keystrokes build combo streaks and charge a mana reservoir that triggers screen-clearing incantations.

Beyond the core single-player arena, the application includes:
- **Practice Trials**: Timed tests (15s, 30s, 60s) measuring raw speed, net speed, accuracy, and keystroke consistency variance.
- **Real-Time 1v1 Duels**: Synchronized head-to-head multiplayer powered by Supabase Realtime room codes with live opponent ghost progress.
- **Progression & Economy**: Persistent XP leveling, prestige titles, consumable upgrades, and an authenticated global leaderboard.

> **Project Milestone**: Architected, designed, and developed independently from prototype to production. Shipped at **version 2.2.6**.

## Architectural Challenges & Technical Decisions

### 1. The 60 FPS Canvas Game Loop vs. DOM Rendering
Most browser typing trainers render words as individual HTML DOM elements. At high typing speeds (120+ WPM) with dozens of simultaneous particles, continuous DOM manipulation triggers severe browser reflows, style recalculations, and layout thrashing.

To achieve sustained **60 FPS on low-tier mobile and desktop devices**, Arcane Typer utilizes a custom HTML5 Canvas rendering pipeline:

- **Delta-Time Normalization**: Physics and word descent speeds are calibrated using frame delta-time (`dt`), guaranteeing identical gameplay velocity regardless of whether a monitor runs at 60Hz, 120Hz, or experiences transient CPU throttling.
- **Object Pooling**: Floating particle effects, mana sparks, and shattered runes draw from a pre-allocated object pool rather than instantiating new objects in memory during frames, eliminating garbage collection pause spikes.
- **Sub-Pixel Crisp Font Alignment**: Uses canvas integer-rounded coordinates during text rendering passes to prevent blurry letterforms.

```javascript
// Frame update with delta-time normalization and barrier collision check
function updateGameLoop(currentTime) {
  const dt = Math.min((currentTime - lastTime) / 1000, 0.1);
  lastTime = currentTime;

  for (let i = activeWords.length - 1; i >= 0; i--) {
    const word = activeWords[i];
    word.y += word.speed * dt;

    if (word.y >= barrierY) {
      triggerBarrierDamage(word.damage);
      activeWords.splice(i, 1);
    }
  }

  renderCanvas(ctx);
  requestAnimationFrame(updateGameLoop);
}
```

### 2. Real-Time Multiplayer Synchronisation over Supabase
For 1v1 duels, deploying and maintaining dedicated stateful WebSocket game servers (e.g. Node.js + Socket.io) would introduce ongoing infrastructure overhead.

Instead, Arcane Typer leverages **Supabase Realtime Broadcast Channels**:
- **Room Code Matchmaking**: Host creates a ephemeral room code stored in Supabase with row-level security (RLS). The guest joins by matching the 6-character room token.
- **State Broadcast & Optimistic Prediction**: Rather than transmitting every individual keyup event across the wire, each client broadcasts a lightweight snapshot payload (`{ wpm, accuracy, wordsCompleted, mana }`) every 150ms or immediately upon word completion.
- **Local Lag Compensation**: Opponent progress bars interpolate smoothly between broadcast ticks using linear interpolation (`lerp`), providing a fluid spectator feel without visual teleportation.

### 3. Precision Keystroke Analytics Engine
Standard typing tests calculate speed naively using `(total words / elapsed minutes)`. Arcane Typer implements high-resolution event timing using `performance.now()` to compute true typing biomechanics:

- **Net WPM vs. Raw WPM**: Uncorrected errors penalize net typing throughput, enforcing accuracy discipline.
- **Keystroke Consistency Variance**: Computes the standard deviation of inter-keystroke intervals (`Δt`). Consistency is scored from 0% to 100%, allowing players to see whether they type in erratic bursts or maintain a rhythmic, ergonomic tempo.

| Metric | Calculation Method | Purpose |
| :--- | :--- | :--- |
| **Raw WPM** | `(All Keystrokes / 5) / TimeInMinutes` | Measures pure mechanical motor speed |
| **Net WPM** | `((All Keystrokes / 5) - UncorrectedErrors) / TimeInMinutes` | Industry standard typing competency |
| **Accuracy** | `(Correct Keystrokes / Total Keystrokes) * 100` | Precision index |
| **Consistency** | `Math.max(0, 100 - (StandardDeviation(Δt) * ScaleFactor))` | Rhythm and flow measurement |

### 4. Zero-Asset Synthesized Audio via Web Audio API
Rather than bloating the application payload with external `.mp3` or `.wav` sound files, key interaction audio is synthesized procedurally in real time:
- Typing clicks are shaped using high-frequency white noise bursts with sharp exponential decay.
- Mana spells and barrier impacts modulate square and sine wave oscillators with low-pass filters.
- Result: **0 KB audio network payload**, zero audio load latency, and dynamic pitch modulation based on current combo multipliers.

## Retrospective & Key Takeaways

1. **State Isolation**: Decoupling the game physics state from the canvas rendering context allowed rapid prototyping of alternative gameplay modes (scrambled words, invisible typing, speed drills) without touching the rendering engine.
2. **Bandwidth Efficiency**: Shifting from event-per-keystroke to interval state snapshots reduced Supabase Realtime channel egress by over 75% during intense 60-second duels.
3. **Mobile Affordance**: Supporting mobile touch typing required custom virtual keyboard listeners and viewport resize lockouts to prevent mobile browser keyboards from destroying the game layout.
